# Contributing to Anvil

Thanks for your interest in helping improve Anvil. This project does not accept
pull requests. The only contributions we accept are issues and discussions.

- Use [GitHub Issues](https://github.com/BrokkAi/anvil/issues) to report bugs or
  propose specific improvements. Search existing issues first to avoid
  duplicates, and include enough detail to reproduce or evaluate the problem.
- Use [GitHub Discussions](https://github.com/BrokkAi/anvil/discussions) for
  questions, ideas, feedback, and broader design conversations.

Please do not open a pull request; it will be closed without review. This policy
applies to all users, including contributions created with AI tools.

Do not include credentials, private source code, or unredacted private
transcripts in issues or discussions. Report suspected vulnerabilities
privately to [feedback@brokk.ai](mailto:feedback@brokk.ai).

All participation must follow the [Code of Conduct](CODE_OF_CONDUCT.md).
