Anvil separates configuration by ownership and lifetime.

## Provider configuration

Provider credentials and model discovery are shared by sessions in an Anvil installation. Use `/setup` inside a session to configure supported providers.

## Session controls

The ACP client owns current-session controls such as model selection, behavior mode, permission mode, reasoning effort, and service tier.

## Install defaults

Sandbox behavior and automatic turn recaps are persisted as installation defaults and seed future sessions.
