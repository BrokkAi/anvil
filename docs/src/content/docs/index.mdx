<section class="home-section">
  <p class="section-label">The boundary is the product</p>
  <h2>Build the interface. Keep the engine.</h2>
  <p>
    Anvil separates the agent runtime from the experience around it. Your client stays small and
    intentional while one reusable ACP subprocess handles execution semantics.
  </p>

  <div class="ownership-grid">
    <article>
      <small>CLIENT OWNS</small>
      <h3>The experience</h3>
      <ul>
        <li>Conversation and task UI</li>
        <li>Permission prompts</li>
        <li>Session controls</li>
        <li>Streaming presentation</li>
      </ul>
    </article>
    <article>
      <small>ANVIL OWNS</small>
      <h3>The agent runtime</h3>
      <ul>
        <li>Model routing and tool loop</li>
        <li>Permission enforcement</li>
        <li>Sessions and context compaction</li>
        <li>Sandboxing and MCP servers</li>
      </ul>
    </article>
  </div>
</section>
